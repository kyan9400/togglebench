# Security policy

## Supported versions

The latest release receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Include reproduction steps, affected versions, and the expected impact. Do not open a public issue for an unpatched vulnerability.

ToggleBench runs entirely in the browser and does not transmit feature-flag configuration or evaluation contexts. Exported JSON may still contain operational naming, so review it before sharing.
