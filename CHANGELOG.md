# Changelog

All notable changes to ToggleBench are documented here.

## 1.0.0 - 2026-08-26

### Added

- Ordered feature-flag targeting with four comparison operators.
- Deterministic 10,000-bucket percentage rollouts.
- Live evaluation trace and representative cohort explorer.
- Independent production and staging configuration.
- Versioned local persistence and JSON export.
- Responsive, accessible interface with reduced-motion support.
- Automated lint, test, build, Pages deployment, and release workflows.
